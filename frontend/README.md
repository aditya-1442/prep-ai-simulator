# PrepAI Frontend

A sleek, premium interview preparation interface powered by **Google Gemini 1.5**.

## ✨ Features
- **Glassmorphic Design**: Modern, clean UI built with Vanilla CSS.
- **Dynamic Flows**: Animated transitions using Framer Motion.
- **URL Ingestion**: Support for multiple source types (web, YouTube).

## 🚀 Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Stack
- **Next.js** (App Router)
- **Lucide React** (Icons)
- **Framer Motion** (Animations)
- **React Markdown** (Content rendering)

---
*Note: This interface connects to a FastAPI backend optimized for high-performance AI generation.*
